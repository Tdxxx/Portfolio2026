Generate an admin password hash

This runs entirely in your browser — nothing is sent anywhere, no network request happens at all.

Type the password you want to use for the admin panel, click Generate, then copy the hash and paste it into PASSWORD_HASH near the top of js/admin-auth.js.

Don't upload this file to your live site — delete it, or just keep it locally. It doesn't need to be part of the deployed repo.
