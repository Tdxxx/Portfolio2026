Manage Projects

This page has no backend — it can't push changes to your live site by itself. It builds a projects.json file for you to download, then commit/upload to your repo alongside your project images. That file is what index.html and project.html read from. Your work here also autosaves to this browser as you go, so an accidental refresh won't lose it.
